# Use Cases

## Admin

- Add, update and deactivate users.
- Add courses.
- View users, courses, reports and action logs.

## Manager

- Approve student course registrations.
- Assign teachers to courses.
- Publish and view news.
- Generate academic performance reports.
- View students sorted by GPA and teachers sorted alphabetically.
- View employee requests.

## Teacher

- View assigned courses.
- Put marks for students enrolled in assigned courses.
- View student information.
- Send messages and complaints as an employee.

## Student

- Log in.
- Register for courses.
- Drop courses.
- View marks and transcript.
- View course teachers.
- Rate teachers.
- For 4th year students, have a research supervisor with h-index at least 3.

## Researcher

- Publish research papers.
- Join research projects.
- Print own papers sorted by comparator.
- Print all university papers sorted by date, citations or length.
- Get top cited researcher by school or by year.

## Demo Flow

1. Admin creates users and course.
2. Manager assigns teacher to course.
3. Student logs in and registers for course.
4. Manager approves registration.
5. Teacher grades student.
6. Student views transcript.
7. Researchers publish papers and join project.
8. System prints sorted research papers and top cited researchers.
9. System generates academic and research reports.
10. System saves data using serialization.
